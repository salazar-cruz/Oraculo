ORÁCULO DA PALMA — PACOTE COMPLETO
PUBLICAÇÃO SEM LINHA DE COMANDOS

Este pacote já contém:
- site completo para GitHub Pages;
- endereço real da API no config.js;
- melhoria da leitura de fotografias;
- imagens enviadas até 2048 px, JPEG 92%;
- rejeição apenas abaixo de 30% de legibilidade;
- modo de diagnóstico público desligado;
- código completo e actualizado do Cloudflare Worker.

A) ACTUALIZAR O SITE NO GITHUB

1. Abre o repositório do Oráculo no GitHub.
2. Substitui os ficheiros da raiz pelos deste pacote:
   index.html
   styles.css
   app.js
   config.js
   CNAME
   .nojekyll
3. Confirma as alterações no GitHub.
4. Aguarda cerca de um minuto e abre:
   https://oraculo.devnexusdigital.com
5. Faz Ctrl+F5.

Não alteres o CNAME nem o DNS da Porkbun.

B) ACTUALIZAR O WORKER NA CLOUDFLARE, SEM CMD

1. Entra na Cloudflare.
2. Abre Workers & Pages.
3. Selecciona: oraculo-da-palma-api
4. Carrega em Edit Code.
5. Apaga todo o código existente.
6. Abre o ficheiro:
   WORKER-CLOUDFLARE-COLAR-NO-EDITOR.js
7. Copia todo o conteúdo e cola no editor da Cloudflare.
8. Carrega em Deploy.

A chave GROQ_API_KEY já configurada no Worker permanece guardada.
Não voltes a colar a chave no código.

C) TESTE

1. Abre:
   https://oraculo-da-palma-api.econsulting-cv.workers.dev
2. Deve aparecer uma resposta com "status":"ok".
3. Abre o site, carrega uma fotografia e inicia a leitura.

IMPORTANTE

A pasta worker fica incluída como cópia integral do projecto, mas não é
necessário executar npm, npx, Wrangler ou qualquer comando para esta
actualização. Para o painel da Cloudflare, usa directamente o ficheiro
WORKER-CLOUDFLARE-COLAR-NO-EDITOR.js.
