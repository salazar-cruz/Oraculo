ORÁCULO DA PALMA v1.5.1
PUBLICAÇÃO SEM LINHA DE COMANDOS

NOVIDADES
- Site integral em português, inglês e francês.
- O idioma escolhido fica guardado no navegador.
- A leitura da Groq é produzida no idioma selecionado.
- Nova secção de estatísticas com total de leituras e contagem por país.
- Não são guardados endereços IP, nomes ou fotografias nas estatísticas.
- O país é identificado pela infraestrutura da Cloudflare e só é guardado o código agregado do país.

A. PUBLICAR O SITE NO GITHUB
1. Abra o repositório do Oráculo da Palma no GitHub.
2. Substitua os ficheiros atuais pelos ficheiros da raiz deste pacote:
   index.html
   styles.css
   app.js
   config.js
   CNAME
   .nojekyll
3. Envie também a pasta assets completa.
4. Confirme as alterações no GitHub.

B. CRIAR O LIVRO DE ESTATÍSTICAS NA CLOUDFLARE
Este passo é feito uma única vez e não exige CMD.

1. Entre no painel da Cloudflare.
2. Abra Workers & Pages > D1 SQL Database.
3. Selecione Create database.
4. Nome: oraculo-stats
5. Abra a base de dados criada e entre em Console.
6. Abra o ficheiro D1-SCHEMA.sql deste pacote.
7. Copie todo o conteúdo, cole na consola SQL e selecione Execute.

C. LIGAR A BASE DE DADOS AO WORKER
1. Abra Workers & Pages > oraculo-da-palma-api.
2. Abra Bindings.
3. Selecione Add binding > D1 database.
4. Variable name: STATS_DB
5. Escolha a base de dados oraculo-stats.
6. Guarde a ligação.

D. ATUALIZAR O CÓDIGO DO WORKER
1. No Worker oraculo-da-palma-api, selecione Edit Code.
2. Abra o ficheiro WORKER-CLOUDFLARE-COLAR-NO-EDITOR.js deste pacote.
3. Copie todo o conteúdo.
4. Apague o código atual do editor da Cloudflare e cole o novo.
5. Selecione Deploy.

A chave GROQ_API_KEY já guardada na Cloudflare mantém-se. Não a coloque no código.

E. TESTAR
Abra:
https://oraculo-da-palma-api.econsulting-cv.workers.dev/

Deve aparecer version 1.5.1 e statistics configured true.

Depois abra:
https://oraculo-da-palma-api.econsulting-cv.workers.dev/stats

No início, o total será zero. Cada leitura concluída com imagem aceite acrescenta uma unidade ao país correspondente.

NOTA
Caso a ligação STATS_DB ainda não esteja feita, as leituras continuam a funcionar. Apenas a secção de estatísticas indica que o livro de registos ainda não está ligado.
